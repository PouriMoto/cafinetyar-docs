# CafeNet OS — راهنمای خدمات کافینت

به سامانه راهنمای عملیاتی کافینت خوش آمدید.

## چطور استفاده کنم؟

از کادر جستجوی بالای صفحه استفاده کنید — می‌توانید:
- **نام خدمت** را جستجو کنید (مثلاً "کارت بازرگانی")
- **کد خدمت** را جستجو کنید (مثلاً "CUS-010")

نتیجه شما را مستقیم به راهنمای گام‌به‌گام همان خدمت می‌برد.

## دسته‌بندی خدمات

از منوی سمت راست، دسته موردنظر (مثلاً «مالیات» یا «گمرک و تجارت») را انتخاب کنید تا لیست کامل خدمات آن دسته را ببینید.

## نکته برای اپراتورها

هر راهنما شامل بخش‌های زیر است:
- **مدارک لازم** — چک‌لیست قبل از شروع کار
- **مراحل انجام کار** — گام‌به‌گام
- **هزینه‌ها**
- **نکات و خطاهای رایج**
- **نیاز به تایید دستی** — مواردی که ممکن است تغییر کرده باشند و باید نزدیک هر استفاده دوباره چک شوند
