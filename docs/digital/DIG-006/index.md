# SOP: امضای الکترونیکی (DIG-006)

## اطلاعات کلی
- دسته: Digital
- سامانه/ابزار: سامانه هدا (aut.ncr.ir) به‌عنوان پایه، یا سامانه‌های تخصصی‌تر مثل «ثبت من» برای امور شرکتی
- فصل/بازه زمانی: Always
- اولویت: C

## توضیح و تفاوت با DIG-007
این خدمت خودِ **فرآیند استفاده از امضای الکترونیکی** برای امضای یک سند/فرم آنلاین است (مثلاً تایید یک قرارداد یا فرم اداری). برای **صدور گواهی رسمی امضای دیجیتال** (که یک مدرک مجزا و رسمی‌تر است، مخصوصاً برای شرکت‌ها)، به DIG-007 مراجعه شود.

## مدارک لازم
- [ ] حساب کاربری فعال در سامانه هدا (پیش‌نیاز، طبق DIG-005) یا سامانه تخصصی مربوطه
- [ ] دسترسی به شماره موبایل برای تایید هر امضا (کد یک‌بارمصرف)

## مراحل انجام کار (برای اپراتور کافینت)
1. بررسی کن مشتری برای چه سندی نیاز به امضای الکترونیکی دارد — این تعیین می‌کند کدام سامانه استفاده شود (خودنویس برای اجاره‌نامه، ثبت من برای امور شرکتی، یا هدا به‌طور عمومی).
2. اگر پیش‌نیاز هدا هنوز انجام نشده، ابتدا DIG-005 را انجام بده.
3. در سامانه مربوطه، سند/فرم موردنظر را باز کن.
4. گزینه «امضای الکترونیکی» را انتخاب کن.
5. سیستم کد تایید به موبایل ثبت‌شده ارسال می‌کند.
6. کد را وارد کن — این امضا هویت فرد را تایید و امنیت سند را تضمین می‌کند.
7. سند امضاشده ذخیره/ارسال می‌شود.

## هزینه‌ها
- استفاده از امضای الکترونیکی معمولاً رایگان یا با هزینه بسیار جزئی است.
- هزینه خدمت کافینت: طبق تعرفه داخلی.

## نکات و خطاهای رایج
- امنیت این امضا کاملاً به حفاظت از دسترسی موبایل و رمزهای شخصی مشتری بستگی دارد — کافینت هرگز نباید این اطلاعات را نگه دارد.
- اگر مشتری قصد امضای سند شرکتی رسمی (مثل تاسیس یا تغییرات شرکت) دارد، احتمالاً به گواهی امضای دیجیتال رسمی‌تر (DIG-007) نیاز دارد، نه فقط این امضای ساده.
