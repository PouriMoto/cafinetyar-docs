# SOP: استعلام سابقه بیمه (INS-008)

## اطلاعات کلی
- دسته: Insurance
- سامانه رسمی: eservices.tamin.ir + کد دستوری #1420*4* + اپلیکیشن «تأمین من»
- فصل/بازه زمانی: Always
- اولویت: A

## مدارک لازم
- [ ] کد ملی
- [ ] شماره موبایل ثبت‌شده در سامانه تامین اجتماعی (برای روش کد دستوری، باید دقیقاً به‌نام خودِ فرد باشد)
- [ ] رمز عبور سامانه (در صورت داشتن حساب کاربری)

## مراحل انجام کار (برای اپراتور کافینت) — سه روش

### روش ۱: سامانه آنلاین (کامل‌ترین اطلاعات)
1. ورود به eservices.tamin.ir.
2. اگر رمز عبور را فراموش کرده، از گزینه «رمز عبور را فراموش کرده‌ام» استفاده کن — کد ملی و کد پیامکی لازم است.
3. جایگزین ورود: گزینه «ورود از طریق دولت من» با شماره تلفن و کد یک‌بارمصرف.
4. بعد از ورود: منوی «بیمه‌شدگان» → «خدمات سابقه» → «کلیه سوابق» یا «سوابق و ریز دستمزد».
5. سوابق را چاپ یا ذخیره کن و به مشتری تحویل بده.

### روش ۲: کد دستوری (سریع، فقط آخرین ماه)
1. تذکر بده که مشتری از قبل باید در sabeghe.tamin.ir ثبت‌نام کرده باشد و شماره موبایلش با شماره ثبت‌شده یکسان باشد.
2. کد `#1420*4*` را با موبایل مشتری شماره‌گیری کن.
3. کد ملی را وارد کن.
4. فقط آخرین ماه سابقه بیمه نمایش داده می‌شود — برای سابقه کامل، روش ۱ لازم است.

### روش ۳: اپلیکیشن «تأمین من»
1. اگر مشتری اپلیکیشن را نصب کرده، با کد ملی و رمز عبور وارد شود.
2. نوع کاربری (بیمه‌شده، مستمری‌بگیر، کارفرما) را انتخاب کند.
3. سوابق به‌صورت نموداری و عددی قابل مشاهده است.

## هزینه‌ها
- استعلام رایگان است.
- هزینه خدمت کافینت: طبق تعرفه داخلی (کار ساده و سریع).

## نکات و خطاهای رایج
- اگر فرد در بیش از یک محل هم‌زمان بیمه پرداخت کرده باشد، فقط یکی به‌عنوان «سابقه تلفیقی» محاسبه می‌شود — این نکته مهمی است که مشتری معمولاً از آن غافل است و باید توضیح داده شود.
- کد دستوری فقط آخرین ماه را نشان می‌دهد، نه کل سابقه — اگر مشتری نیاز به گزارش کامل دارد (مثلاً برای محاسبه بازنشستگی)، حتماً روش سامانه آنلاین را استفاده کن.
- اگر سابقه‌ای ثبت نشده یا اشتباه است، این مشکل باید با مراجعه حضوری به شعبه تامین اجتماعی حل شود — کافینت نمی‌تواند اصلاح سابقه انجام دهد.
