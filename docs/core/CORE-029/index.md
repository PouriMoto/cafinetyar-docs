# SOP: پرینت از موبایل (CORE-029)

## اطلاعات کلی
- دسته: Printing
- سامانه/ابزار: بلوتوث، Wi-Fi Direct، کابل داده، یا ارسال فایل از طریق ایمیل/تلگرام به سیستم کافینت
- فصل/بازه زمانی: Always
- اولویت: A

## مدارک لازم
- [ ] گوشی موبایل مشتری حاوی فایل/عکس موردنظر

## مراحل انجام کار (برای اپراتور کافینت) — چند روش

### روش ۱: انتقال مستقیم (بلوتوث/کابل)
1. اتصال گوشی مشتری به سیستم از طریق کابل USB یا بلوتوث.
2. انتقال فایل موردنظر به سیستم کافینت.
3. باز کردن و چاپ فایل.

### روش ۲: از طریق فضای ابری/پیام‌رسان (اگر انتقال مستقیم ممکن نیست)
1. از مشتری بخواه فایل را به ایمیل خودش یا خودِ کافینت (در صورت وجود ایمیل اختصاصی) یا از طریق تلگرام/واتساپ ارسال کند.
2. دریافت فایل روی سیستم کافینت.
3. چاپ طبق نیاز.

## هزینه‌ها
- هزینه بر اساس تعداد صفحه/عکس، طبق تعرفه داخلی.

## نکات و خطاهای رایج
- بعد از اتمام کار، فایل ارسالی مشتری (عکس یا سند) را از سیستم کافینت و از هرگونه چت/ایمیل موقت پاک کن تا حریم خصوصی مشتری حفظ شود.
- برخی عکس‌های موبایل کیفیت پایین یا فرمت غیرمعمول دارند — قبل از چاپ نهایی حجم بالا، یک تست بگیر.

## منابع
- سیستم داخلی کافینت
