# SOP: نوبت‌گیری اینترنتی (CORE-044)

## اطلاعات کلی
- دسته: General
- سامانه/ابزار: بسته به نوع نوبت متفاوت (پزشک، اداره، بانک و غیره)
- فصل/بازه زمانی: Always
- اولویت: A

## توضیح
این خدمت پوششی برای هر نوع نوبت‌گیری آنلاین است که در SOP های تخصصی دیگر نیامده — برای نوبت پزشک به HLT-001، برای نوبت تعویض پلاک به VEH-008 مراجعه شود؛ این SOP برای سایر انواع نوبت (اداری، بانکی، مشاوره) است.

## مدارک لازم
- [ ] کد ملی یا شماره موبایل (بسته به سامانه)

## مراحل انجام کار (برای اپراتور کافینت)
1. از مشتری بپرس دقیقاً برای چه کاری نوبت لازم دارد — اگر پزشک یا تعویض پلاک بود، به SOP تخصصی مربوطه هدایتش کن.
2. برای سایر موارد، سایت/سامانه مربوطه را جستجو و پیدا کن.
3. ثبت‌نام یا ورود به سامانه.
4. انتخاب تاریخ و ساعت مناسب از تقویم نمایش‌داده‌شده.
5. تایید نهایی و دریافت کد نوبت — چاپ و به مشتری تحویل بده.

## هزینه‌ها
- معمولاً نوبت‌گیری رایگان است.
- هزینه خدمت کافینت: طبق تعرفه داخلی.

## نکات و خطاهای رایج
- همیشه اول دقیق‌ترین SOP تخصصی مرتبط را چک کن قبل از استفاده از این نسخه عمومی.

## منابع
