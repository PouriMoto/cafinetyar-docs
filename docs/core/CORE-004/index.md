# SOP: کپی سیاه و سفید (CORE-004)

## اطلاعات کلی
- دسته: Printing
- سامانه/ابزار: دستگاه کپی/چندکاره داخلی کافینت
- فصل/بازه زمانی: Always
- اولویت: A

## مدارک لازم
- [ ] سند اصلی برای کپی

## مراحل انجام کار (برای اپراتور کافینت)
1. دریافت سند اصلی از مشتری.
2. بررسی کیفیت سند مبدا (تا و کثیفی می‌تواند کیفیت کپی را کم کند).
3. قرار دادن روی دستگاه کپی، تنظیم اندازه کاغذ (A4، A3 و غیره).
4. پرسیدن تعداد نسخه‌های موردنیاز.
5. کپی و بررسی کیفیت خروجی.
6. تحویل سند اصلی و نسخه‌های کپی‌شده به مشتری — **همیشه سند اصلی مشتری را در پایان کار به او پس بده**، این نکته امنیتی مهمی است.

## هزینه‌ها
- هزینه بر اساس تعداد صفحه، طبق تعرفه داخلی.

## نکات و خطاهای رایج
- برای مدارک هویتی مهم (کارت ملی، شناسنامه)، دقت کن کل صفحه به‌درستی و کامل کپی شود، نه بریده یا کج.
- سند اصلی مشتری هرگز نباید فراموش یا جا گذاشته شود.

## منابع
- ابزار داخلی کافینت
