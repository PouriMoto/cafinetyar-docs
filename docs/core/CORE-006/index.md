# SOP: اسکن مدارک (CORE-006)

## اطلاعات کلی
- دسته: Printing
- سامانه/ابزار: اسکنر یا دستگاه چندکاره داخلی کافینت
- فصل/بازه زمانی: Always
- اولویت: A

## مدارک لازم
- [ ] سند اصلی برای اسکن
- [ ] فلش یا آدرس ایمیل مشتری برای دریافت فایل خروجی

## مراحل انجام کار (برای اپراتور کافینت)
1. دریافت سند اصلی از مشتری.
2. قرار دادن روی اسکنر، تنظیم رزولوشن مناسب (برای مدارک هویتی معمولاً ۳۰۰ DPI کافی و خوانا است).
3. انتخاب فرمت خروجی (PDF یا تصویر JPG/PNG) طبق نیاز مشتری.
4. اسکن و بررسی کیفیت و خوانایی خروجی — مخصوصاً برای مدارک هویتی، متن باید کاملاً خوانا باشد.
5. ذخیره فایل روی فلش مشتری یا ارسال به ایمیل او.
6. تحویل سند اصلی به مشتری.

## هزینه‌ها
- هزینه بر اساس تعداد صفحه، طبق تعرفه داخلی.

## نکات و خطاهای رایج
- برای مدارک چندصفحه‌ای (مثل شناسنامه)، بپرس آیا مشتری یک فایل PDF چندصفحه‌ای می‌خواهد یا فایل‌های جداگانه.
- بعد از اسکن، هرگز فایل مدارک هویتی مشتری روی سیستم کافینت باقی نماند — بلافاصله بعد از انتقال به فلش/ایمیل مشتری، فایل را از سیستم کافینت پاک کن؛ این یک نکته حفاظت از حریم خصوصی مهم است.

## منابع
- ابزار داخلی کافینت
