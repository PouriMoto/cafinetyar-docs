# SOP: پرینت رنگی (CORE-002)

## اطلاعات کلی
- دسته: Printing
- سامانه/ابزار: پرینتر رنگی داخلی کافینت
- فصل/بازه زمانی: Always
- اولویت: A

## مدارک لازم
- [ ] فایل موردنظر

## مراحل انجام کار (برای اپراتور کافینت)
1. دریافت فایل از مشتری.
2. بررسی محتوا و رنگ‌بندی با مشتری، مخصوصاً برای عکس یا طرح‌های گرافیکی.
3. تنظیم پرینتر روی حالت رنگی و کیفیت مناسب (پیش‌نویس/معمولی/بهترین کیفیت).
4. پرسیدن نوع کاغذ (معمولی، گلاسه، مات) و تعداد نسخه.
5. چاپ تستی برای بررسی صحت رنگ‌ها در صورت حجم بالا یا اهمیت رنگ (مثل عکس).
6. چاپ نهایی و تحویل.

## هزینه‌ها
- هزینه بر اساس تعداد صفحه و نوع کاغذ، معمولاً بیشتر از پرینت سیاه‌وسفید (CORE-001).

## نکات و خطاهای رایج
- کیفیت رنگ روی صفحه نمایش با کیفیت چاپ‌شده ممکن است متفاوت باشد — همیشه یک تست بگیر، مخصوصاً برای کارهای حساس (رزومه با لوگو، عکس).
- کمبود جوهر رنگی رایج‌ترین دلیل افت کیفیت چاپ است — قبل از کار مهم، سطح جوهر را چک کن.
