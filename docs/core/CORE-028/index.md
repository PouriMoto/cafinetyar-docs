# SOP: پرینت از فلش (CORE-028)

## اطلاعات کلی
- دسته: Printing
- سامانه/ابزار: سیستم کافینت با پورت USB
- فصل/بازه زمانی: Always
- اولویت: A

## مدارک لازم
- [ ] فلش مموری حاوی فایل موردنظر

## مراحل انجام کار (برای اپراتور کافینت)
1. دریافت فلش از مشتری.
2. **پیش از باز کردن، در صورت امکان با آنتی‌ویروس سیستم کافینت اسکن کن** — این یک اقدام پیشگیرانه امنیتی برای محافظت از سیستم کافینت در برابر ویروس است.
3. پیدا کردن فایل موردنظر با مشتری.
4. باز کردن فایل و بررسی صحت محتوا.
5. چاپ طبق نیاز مشتری (سیاه‌وسفید یا رنگی، تعداد نسخه).
6. بعد از اتمام کار، فلش را ایمن جدا (Safely Remove) و به مشتری تحویل بده.

## هزینه‌ها
- هزینه بر اساس تعداد صفحه، طبق تعرفه داخلی.

## نکات و خطاهای رایج
- فلش‌های ناشناس می‌توانند حامل ویروس باشند — اسکن قبل از باز کردن، ریسک آلودگی سیستم کافینت را کاهش می‌دهد.
- بعد از اتمام کار، هیچ فایلی از فلش مشتری نباید روی سیستم کافینت کپی یا نگه‌داری شود، مگر با درخواست صریح مشتری.

## منابع
- سیستم داخلی کافینت
