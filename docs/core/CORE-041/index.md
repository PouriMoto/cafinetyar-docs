# SOP: ساخت رزومه (CORE-041)

## اطلاعات کلی
- دسته: General
- سامانه/ابزار: Word یا قالب‌های آماده رزومه
- فصل/بازه زمانی: Always
- اولویت: A

## مدارک لازم
- [ ] اطلاعات کامل مشتری: تحصیلات، سوابق کاری، مهارت‌ها، اطلاعات تماس
- [ ] عکس پرسنلی (در صورت نیاز برای نوع خاصی از رزومه)

## مراحل انجام کار (برای اپراتور کافینت)
1. مصاحبه کوتاه با مشتری برای جمع‌آوری اطلاعات: تحصیلات، سوابق شغلی (با تاریخ دقیق)، مهارت‌ها، زبان‌ها، دستاوردها.
2. پرسیدن نوع شغل مدنظر تا رزومه متناسب با آن (رسمی/اداری یا خلاقانه) طراحی شود.
3. انتخاب قالب مناسب و تایپ اطلاعات به‌صورت منظم و حرفه‌ای.
4. سازمان‌دهی بخش‌ها: اطلاعات تماس، خلاصه حرفه‌ای، سوابق کاری (جدید به قدیم)، تحصیلات، مهارت‌ها.
5. بررسی نهایی با مشتری از نظر دقت تاریخ‌ها و عناوین.
6. ذخیره فایل و ارائه نسخه چاپی/دیجیتال.

## هزینه‌ها
- هزینه بر اساس پیچیدگی و زمان‌بری کار، طبق تعرفه داخلی — این خدمت وقت‌گیرتر از ویرایش ساده است.

## نکات و خطاهای رایج
- از مشتری بخواه اطلاعات را دقیق و دسته‌بندی‌شده بدهد (نه فقط شفاهی و پراکنده) تا رزومه منسجم شود.
- هرگز اطلاعات یا مهارتی که مشتری ذکر نکرده به رزومه اضافه نکن.
- برای مشاغل خاص (فنی، پزشکی، حقوقی)، ممکن است قالب و بخش‌های تخصصی متفاوتی لازم باشد.
