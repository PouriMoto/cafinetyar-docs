# SOP: پرداخت قبوض (CORE-046)

## اطلاعات کلی
- دسته: General
- سامانه/ابزار: همان روش‌های UTL-002 (پرداخت قبض آب/برق/گاز) یا پلتفرم‌های واسط
- فصل/بازه زمانی: Always
- اولویت: A

## توضیح
این خدمت اساساً همان UTL-002 است اما به‌عنوان یک ورودی عمومی‌تر در دسته CORE هم گنجانده شده — برای جزئیات کامل به UTL-002 مراجعه شود.

## مراحل انجام کار (خلاصه، برای جزئیات به UTL-002 مراجعه شود)
1. شناسایی نوع قبض (آب، برق، گاز، تلفن، عوارض).
2. استعلام مبلغ (طبق UTL-001).
3. پرداخت آنلاین با کارت بانکی مشتری — با نظارت خودِ او، بدون نگه‌داری رمز دوم/CVV2 توسط اپراتور.
4. چاپ رسید.

## هزینه‌ها
- هزینه خدمت کافینت: طبق تعرفه داخلی (کار ساده و سریع).

## روش جایگزین (پلتفرم واسط)
قبضینو و ایقبض امکان پرداخت تجمیعی چند قبض مختلف را می‌دهند — جزئیات در `03-Knowledge/00-parallel-platforms-overview.md`.
