# SOP: لمینت (CORE-023)

## اطلاعات کلی
- دسته: Printing
- سامانه/ابزار: دستگاه لمینت داخلی کافینت
- فصل/بازه زمانی: Always
- اولویت: A

## مدارک لازم
- [ ] سند/کارت/جلد موردنظر برای لمینت

## مراحل انجام کار (برای اپراتور کافینت)
1. دریافت سند از مشتری.
2. بررسی اندازه سند و انتخاب پوشش لمینت مناسب (اندازه کارت، A4، یا سایز خاص جلد پایان‌نامه).
3. قرار دادن سند داخل پوشش لمینت به‌درستی (بدون کج شدن یا حباب هوا).
4. عبور دادن از دستگاه لمینت با دمای مناسب.
5. بررسی کیفیت نهایی (عدم وجود حباب، چروک، یا برش نامناسب لبه‌ها).
6. تحویل به مشتری.

## هزینه‌ها
- هزینه بر اساس اندازه و تعداد، طبق تعرفه داخلی.

## نکات و خطاهای رایج
- برای مدارک هویتی اصل (کارت ملی، شناسنامه)، لمینت کردن ممکن است بعداً مشکل ایجاد کند چون برخی ادارات نسخه لمینت‌شده مدارک را برای تغییرات بعدی نمی‌پذیرند — این نکته را به مشتری هشدار بده، مخصوصاً اگر سند اصلی (نه کپی) است.
- دمای نامناسب دستگاه می‌تواند باعث سوختن یا کج شدن سند شود — همیشه با یک نمونه ساده تست کن اگر مطمئن نیستی.
