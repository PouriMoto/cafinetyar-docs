# SOP: تبدیل Word به PDF (CORE-015)

## اطلاعات کلی
- دسته: Printing
- سامانه/ابزار: Word (Save As PDF)
- فصل/بازه زمانی: Always
- اولویت: A

## مدارک لازم
- [ ] فایل Word مبدا

## مراحل انجام کار (برای اپراتور کافینت)
1. دریافت فایل Word از مشتری.
2. باز کردن فایل در Word.
3. استفاده از گزینه «Save As» یا «Export» و انتخاب فرمت PDF.
4. بررسی فایل PDF خروجی از نظر فرمت‌بندی (صفحه‌بندی، فونت‌ها) با مشتری.
5. ذخیره و تحویل فایل PDF نهایی.

## هزینه‌ها
- هزینه بر اساس تعداد صفحه، طبق تعرفه داخلی.

## نکات و خطاهای رایج
- این تبدیل معمولاً بدون مشکل و باکیفیت بالا انجام می‌شود؛ فقط دقت کن فونت‌های فارسی خاص در سیستم نصب باشند تا در PDF درست نمایش داده شوند.

## منابع
- Microsoft Word
