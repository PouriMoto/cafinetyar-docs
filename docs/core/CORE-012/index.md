# SOP: ویرایش فایل Word (CORE-012)

## اطلاعات کلی
- دسته: Printing
- سامانه/ابزار: Microsoft Word
- فصل/بازه زمانی: Always
- اولویت: A

## مدارک لازم
- [ ] فایل Word موجود (از فلش، ایمیل یا آپلود)

## مراحل انجام کار (برای اپراتور کافینت)
1. دریافت فایل از مشتری.
2. باز کردن فایل در Word و بررسی با مشتری چه تغییراتی لازم است (متن، فرمت، تصویر، جدول).
3. اعمال تغییرات دقیقاً طبق خواسته مشتری.
4. بررسی نهایی فایل با مشتری قبل از ذخیره.
5. ذخیره فایل (با همان فرمت یا فرمت جدید طبق درخواست) و تحویل روی فلش/ایمیل یا آماده‌سازی برای چاپ.

## هزینه‌ها
- هزینه بر اساس میزان و پیچیدگی ویرایش، طبق تعرفه داخلی.

## نکات و خطاهای رایج
- برای اسناد رسمی/حقوقی، هرگونه تغییر محتوایی باید دقیقاً طبق خواست مشتری باشد، نه برداشت شخصی اپراتور.
- همیشه یک نسخه پشتیبان از فایل اصلی قبل از ویرایش نگه دار تا در صورت اشتباه قابل بازگشت باشد.

## منابع
- Microsoft Word
