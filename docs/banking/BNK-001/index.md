# 🎯 قبل از شروع کار


!!! warning "اولین سوال اپراتور"

    ابتدا از مشتری بپرسید:

    **کدام بانک و چه نوع حسابی نیاز دارید؟**

    هر بانک سامانه اختصاصی خود را دارد و سامانه یکپارچه برای همه بانک‌ها وجود ندارد.


نمونه‌ها:

- بانک ملی → بام
- بانک ملت → همراه بانک ملت
- بانک سپه → همراه بانک سپه
- بانک مهر ایران → QBank
- بانک رسالت → mresalat.ir
- سایر بانک‌ها → اپلیکیشن اختصاصی بانک

# ⚙️ مراحل انجام کار اپراتور

- [ ] تعیین بانک مورد نظر مشتری

- [ ] تعیین نوع حساب:
    - [ ] پس‌انداز
    - [ ] قرض‌الحسنه
    - [ ] جاری

- [ ] نصب اپلیکیشن بانک مربوطه

- [ ] ثبت شماره موبایل و دریافت کد تایید

- [ ] انجام احراز هویت

- [ ] اسکن کارت ملی یا ورود اطلاعات

- [ ] انجام تصویر سلفی در صورت درخواست بانک

- [ ] تکمیل اطلاعات هویتی و شغلی

- [ ] بارگذاری مدارک مورد نیاز

- [ ] ثبت نهایی درخواست

- [ ] اطلاع‌رسانی ارسال کارت بانکی


**نکات ویژه برای بانک مهر ایران (QBank):**

- [ ] نرم‌افزار QBank فقط روی گوشی‌های Android یا iOS قابل نصب است
- [ ] احراز هویت با امضای لمسی روی صفحه گوشی انجام می‌شود
- [ ] برای احراز هویت، عکس و ویدیو از مشتری گرفته می‌شود
- [ ] حسابی که برای سپرده انتخاب می‌شود، حساب دیجیتال خواهد بود
- [ ] در صورت درخواست کارت، کارت از تهران ارسال می‌شود
- [ ] در صورت عدم درخواست کارت، مشتری می‌تواند همان لحظه از شعبه انتخابی کارت دریافت کند


**نکات ویژه برای بانک رسالت (mresalat.ir):**

- [ ] ورود به سامانه mresalat.ir از طریق مرورگر موبایل (Android یا iOS)
- [ ] انتخاب بخش اشخاص حقیقی و گزینه "حساب جدید"
- [ ] ورود اطلاعات هویتی شامل شماره ملی و شماره موبایل برای دریافت کد اعتبارسنجی
