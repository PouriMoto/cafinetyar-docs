# 🎯 قبل از شروع کار

!!! warning "اولین سوال اپراتور"
    ابتدا از مشتری بپرسید:
    **کدام بانک و چه نوع حسابی نیاز دارید؟**

    هر بانک سامانه اختصاصی خود را دارد و سامانه یکپارچه برای همه بانک‌ها وجود ندارد.

### سامانه‌های بانک‌های مختلف:

| بانک | سامانه/اپلیکیشن | توضیحات |
|------|----------------|----------|
| بانک ملی | بام | اپلیکیشن موبایل |
| بانک ملت | همراه بانک ملت | اپلیکیشن موبایل |
| بانک سپه | همراه بانک سپه | اپلیکیشن موبایل |
| بانک مهر ایران | QBank | **نیاز به نصب نرم‌افزار QBank** |
| بانک رسالت | mresalat.ir | **از طریق سامانه mresalat در بخش اشخاص حقیقی** |
| سایر بانک‌ها | اپلیکیشن اختصاصی بانک | - |

# ⚙️ مراحل انجام کار اپراتور

- [ ] تعیین بانک مورد نظر مشتری

- [ ] تعیین نوع حساب:
    - پس‌انداز
    - قرض‌الحسنه
    - جاری

### برای بانک مهر ایران (QBank):
- [ ] نصب نرم‌افزار QBank روی گوشی (فقط Android یا iOS)
- [ ] ورود شماره ملی و شماره موبایل برای دریافت کد اعتبارسنجی
- [ ] انجام احراز هویت با امضای لمسی روی صفحه گوشی
- [ ] ثبت اطلاعات هویتی
- [ ] گرفتن عکس و ویدیو برای احراز هویت
- [ ] انتخاب حساب سپرده (حساب دیجیتال خواهد بود)
- [ ] انتخاب دریافت کارت:
    - **اگر تیک کارت زده شود:** کارت از تهران ارسال می‌شود
    - **اگر تیک کارت زده نشود:** می‌توان بلافاصله از شعبه انتخاب‌شده تحویل گرفت

### برای بانک رسالت (mresalat):
- [ ] ورود به سامانه mresalat.ir
- [ ] انتخاب بخش اشخاص حقیقی
- [ ] انتخاب گزینه "حساب جدید"
- [ ] ورود اطلاعات هویتی (کد ملی و شماره موبایل)
- [ ] انجام احراز هویت

### سایر بانک‌ها:
- [ ] نصب اپلیکیشن بانک مربوطه
- [ ] ثبت شماره موبایل و دریافت کد تایید
- [ ] انجام احراز هویت
- [ ] اسکن کارت ملی یا ورود اطلاعات
- [ ] انجام تصویر سلفی در صورت درخواست بانک
- [ ] تکمیل اطلاعات هویتی و شغلی
- [ ] بارگذاری مدارک مورد نیاز
- [ ] ثبت نهایی درخواست
- [ ] اطلاع‌رسانی ارسال کارت بانکی

# ⚠️ خطاهای رایج

!!! danger "مواردی که باعث توقف فرآیند می‌شود"

**۱- سیم کارت به نام مشتری نیست**

راهکار: ابتدا مالکیت سیم کارت بررسی شود.

**۲- مشکل چک برگشتی**

برای حساب جاری مشتری را به SOP زیر ارجاع دهید:
➡️ [رفع سوءاثر چک - BNK-005](../BNK-005)

**۳- مشتری زیر ۱۸ سال است**

 نیاز به حکم رشد دادگاه دارد و گرنه باید به همراه والدین به شعبه مراجعه نمایند تا افتتاح حساب کند و اینترنتی ممکن نیست

**۴- عدم تطابق شماره موبایل با کد ملی**

اطمینان حاصل کنید شماره موبایل به نام خود مشتری ثبت شده باشد.
