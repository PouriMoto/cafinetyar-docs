## حالا جواب سوال اصلی‌ات: چه فایل‌هایی باید عوض شوند؟

این را به‌صورت یک **چک‌لیست ثابت** برایت می‌دهم — هر بار که یک SOP را تغییر می‌دهی یا اضافه می‌کنی، دقیقاً همین ترتیب را دنبال کن:

### حالت ۱: فقط محتوای یک SOP موجود را اصلاح/کامل کردی (مثل کاری که الان کردیم)

| فایل | باید عوض شود؟ | چرا |
|---|---|---|
| `docs/[دسته]/[ID]/index.md` | ✅ بله | خودِ محتوا |
| `service-catalog.csv` (ستون Status) | فقط اگر از TODO به DONE رفت | برای ردیابی پیشرفت کلی |
| `mkdocs.yml` | ❌ نه | لینک منو از قبل درست است |
| فایل‌های Workflow (`workflows/*.md`) | فقط اگر آن ID عضو یکی از ۴ گراف بود | باید هماهنگ بماند |

### حالت ۲: یک SOP کاملاً جدید ساختی (ID ای که در `mkdocs.yml` نبود)

اینجا باید **دو فایل اضافه** شوند که در حالت ۱ نبودند:

| فایل | کار لازم |
|---|---|
| `docs/[دسته]/[ID]/index.md` | فایل جدید بساز |
| `mkdocs.yml` | یک خط جدید زیر دسته مربوطه در بخش `nav:` اضافه کن |
| `service-catalog.csv` | Status را `DONE` کن (اگر از قبل TODO بوده) |

### حالت ۳: خدمتی کاملاً جدید کشف کردی که حتی در Catalog هم نبود (مثل کاری که با سایت‌های cafeneti.com و kafinetonline.com کردیم)

اینجا **سه فایل اصلی Catalog** هم باید عوض شوند:

| فایل | کار لازم |
|---|---|
| `service-catalog.csv` | ردیف جدید با ID بعدی همان Work Package |
| `service-taxonomy.yaml` | اگر پورتال جدیدی کشف شد، به بخش `portals_confirmed_by_search` اضافه شود |
| `operation-roadmap.md` | یک خط در بخش «افزوده‌های Gap-Fill» برای مستند کردن چرا/کی اضافه شد |
| سپس همان دو فایل حالت ۲ (`index.md` + `mkdocs.yml`) |

## چطور به من بگویی که چیزی عوض شده — فرمت پیشنهادی

برای این‌که من سریع بفهمم دقیقاً کدام فایل‌ها باید هماهنگ شوند، این فرمت کوتاه را پیشنهاد می‌کنم وقتی گزارش می‌دهی:

```
[ID] - [نوع تغییر: اصلاح محتوا / SOP جدید / خدمت کاملاً جدید] - [توضیح کوتاه چی عوض شد]
```

مثال‌ها:
```
BNK-001 - اصلاح محتوا - آدرس اپلیکیشن بانک ملی عوض شده، الان "من بانک ملی" نه "بام"
EDU-015 - SOP جدید - تا حالا نساخته بودیم، حالا با فرمت جدید ساختم
MSK-003 - خدمت کاملاً جدید - پیدا کردم "مجوز کارواش" که در Catalog نبود
```

این‌طور من دقیقاً می‌دانم باید فقط `index.md` را چک کنم، یا باید `mkdocs.yml` هم دستکاری شود، یا باید کل زنجیره Catalog (CSV + taxonomy + roadmap) هم به‌روز شود — بدون این‌که هربار از اول همه‌چیز را حدس بزنم یا فراموش کنم یک فایل را هماهنگ کنم.https://pourimoto.github.io/cafinetyar-docs/
